# MAILTRACE-2.0-AI-Powered-Email-Forensics-Threat-Intelligence-Platform
MAILTRACE 2.0 is an AI-powered email security platform for detecting and investigating phishing, spoofing, BEC, and other cyber threats. It analyzes email headers, content, SPF, DKIM, DMARC, and threat patterns using AI/ML to provide actionable security intelligence.
